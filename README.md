# Cok Ciddi Felsefi Hesaplayici

Bu repository, insanlık tarihinin en önemli matematiksel problemini çözmek için yaratılmıştır: **2 + 2**.

## Neden Bu Kadar Ciddi?

Çünkü basit bir hesaplama sandığınız şey aslında varolusun anlamını sorgulamaktır. Kod, önce şunları düşünür:

- Matematik gerçek mi yoksa insan uydurması mı?
- 4 sayısı özgür iradeye sahip midir?
- Evrende 2 tane 2 varsa, toplamları neden 4 olmak zorunda?

Sonra, büyük bir ciddiyetle **4** der.

## Kurulum

```bash
python main.py
```

## Uyarı

Bu kod çok ciddi olduğu için bilgisayarınızın varolussal kriz geçirmesine neden olabilir. Sorumluluk kabul edilmez.
